# One-Line RPG visual assets

The current prototype uses lightweight Canvas vector sprites so it stays fast at small window sizes. The visual direction is compatible with the CC0 packs below; these are the planned source references for replacing the vector silhouettes with sprite sheets.

- [Kenney Abstract Platformer](https://kenney.nl/assets/abstract-platformer) — CC0
- [OpenGameArt CC0 Platform Creatures & Characters](https://opengameart.org/content/cc0-2d-platform-creatures-characters) — CC0 collection

The game already animates movement and combat telegraphs procedurally. Sprite-sheet integration should preserve the current animation states: idle, move, attack, telegraph, hit, and defeat.
