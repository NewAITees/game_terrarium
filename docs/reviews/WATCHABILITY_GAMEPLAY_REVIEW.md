# Watchability Gameplay Review — 放置して眺め続けたくなるゲームへ

作成: 2026-07-12

## この文書の位置づけ

この文書は実装済み・未実装を列挙するTODOではない。`game_terrarium`を、操作の合間に画面を眺めるだけでも面白いゲーム群へ育てるための、ゲーム性レビューと設計判断の材料である。

主題は「AIが動いている」ことではなく、観察者が以下を繰り返したくなることにある。

1. 次に起きることを予想する
2. 予想が当たるか、意外な形で外れるのを見る
3. なぜそうなったかを追う
4. 次の局面を待つ、または小さく条件を変える

## 観察ゲームの核

放置して面白いゲームには、予測可能性と不確実性が同居する。

- 完全に予測不能なら、観察者は原因を追えない
- 完全に予測可能なら、観察者は待つ理由を失う
- 良い状態は、原理は読めるが結果は断定できない状態である

そのため、全ゲームは次の循環を持つべきである。

```text
予兆 → 期待 → 事故／逆転 → 余波 → 次の予兆
```

例:

- 鉱石航路の混雑 → 工場停止の予感 → 輸送船撃沈 → 帝国の生産崩壊 → 遠方鉱山への進出
- 交差点の滞留 → 救急車の遅延予感 → 信号切替の失敗 → 迂回路の混雑 → 道路工事の発生
- 感染ノードの増加 → 前線崩壊の予感 → Seniorの判断失敗 → 一部ネットワークの切断 → 防衛構成の変化

`Against the Storm`が環境圧、選択、短い決着を重ねて都市運営を毎回異なる問題にしている点は、短時間観察ゲームの参考になる。Twitch Plays Pokémonでは、多数の細かな偶然が共同で英雄・失敗・神話に変換された。重要なのは“出来事が起きる”ことだけでなく、人がそれに名前と因果を与えられることである。

参考:

- [Against the Storm — Steam](https://store.steampowered.com/app/1336490/_Against_the_Storm/?l=english)
- [Twitch Plays Pokémonの同時進行の物語性](https://www.engadget.com/2014-02-26-twitch-plays-pokemon-creating-an-oral-history-in-real-time.html)

## 全ゲーム共通の改善軸

### 1. 次の転換点を一文で示す

HUDは現状の数値表示を置き換えず、その上に「今なにを見るべきか」を一文で置く。

- `赤陣営は18秒以内に補給線を失う見込み`
- `北交差点の滞留が臨界値に近い`
- `中央ノードが落ちると西側が孤立する`

これは答えを教えるUIではない。観察者が自分で反証できる仮説を渡すUIである。

### 2. 危機を三段階の予兆にする

平常、兆候、危機を色だけでなく、速度、群れ方、線の密度、UIの短文で区別する。危機が発生してから通知するより、危機になる前の数十秒を面白くする。

### 3. 因果を三段まで遡れるようにする

ログはイベントの羅列ではなく、短い因果連鎖を持つ。

```text
輸送船3隻を喪失
  → 工場p4の在庫が枯渇
  → Red Meridianの艦隊生産が停止
```

複雑なデータを常時見せる必要はない。重要な転換だけを因果カードとして残す。

### 4. AIの人格を“執着”として見せる

攻撃的、防衛的のような重みだけでは人格は記憶に残りにくい。各AIは、状況が悪くても守る原則や、繰り返してしまう失敗を1つ持つとよい。

- 補給線を絶対に捨てない
- 首都が危険でも最後の鉱山を取りに行く
- 弱い同盟者を見捨てない
- 中央の交通を優先して周辺を犠牲にする

### 5. 小さな失敗を世界の変化へ接続する

1隻の撃沈、1台の事故、1ノードの再起動失敗が、数十秒後に勢力図・物流・生態系へ影響する構造を増やす。観察者が「あれが原因だった」と発見できることが、放置観察の手応えになる。

### 6. 介入は強化ではなく条件変更にする

単なる資源追加より、局所的な世界条件の変更が強い。

- この一帯だけ停電
- 30秒だけ通信遅延
- 一道路線だけ閉鎖
- 特定勢力の信用を下げる

介入後には必ず復興、報復、新秩序などの余波を残す。

### 7. 中継・ドキュメンタリー視点を作る

危機地点、初衝突、逆転、最後の1ユニットに、軽いカメラ寄せ、短いスロー、要約パネルを使う。目的は派手さではなく、観察者の視線を「意味のある場所」へ導くことである。

### 8. 一局の名場面を残す

終了時に勝者だけでなく、次を残す。

- 最長生存ユニット
- 最も混雑した地点
- 最初の崩壊原因
- 最大の逆転
- 最重要だった介入

これにより一局が単なる乱数の実行ではなく、話せる出来事になる。

## ゲーム別の提案

### AI Planet Strategy

このプロジェクトで最も“観察戦略ゲーム”になりやすい。物流、工場停止、艦隊、占領、8分決着がすでに揃っているため、追加すべきなのは情報量より局面の意味である。

- 帝国ごとに戦争理由を生成する。鉱石枯渇、補給線への報復、古い領土、危険な工場を巡る競合など。
- 補給線を艦隊の明確な生命線にする。補給が切れると修理、弾薬、出撃効率が落ちる。
- AIが危険航路に対して護衛、迂回、保険的な備蓄を選ぶようにする。
- 重要な艦隊・船団だけに呼び名を付ける。例: `第3護衛群`、`最後の鉱山船`。
- 輸送船撃沈時に、失われた貨物と停止リスクのある工場を因果表示する。
- 中盤に、防衛か遠方鉱山か、工場再建か艦隊生産かを選ぶ局面を置く。
- 占領直後は安定化期間にする。反乱、通信再接続、施設復旧があり、勝者もすぐには安全にならない。
- 崩壊帝国を完全に消さず、亡命艦隊、傭兵、海賊化などの後半要素に変える。
- 終盤の資源枯渇を一律の圧力ではなく、最後の豊富な鉱山を巡る地政学にする。
- 0:00から終了までの戦況年表を出す。初接触、補給線断絶、首都陥落、最大逆転を記録する。

### Escort TD

自動護衛の見た目はあるため、次は“誰がなぜ護衛され、敵がなにを狙うか”を濃くする。

- KINGに目的地ごとの性格を持たせる。急ぐ、護衛を待つ、安全な道を選ぶ。
- 敵の勝ち筋を分ける。直接襲撃、道路封鎖、砲撃、陽動、空襲。
- Pawnの索敵、Rookの足止め、Bishopの長距離火力などを相互依存にする。
- 3ウェーブを1作戦として扱い、偵察、圧力、決戦のように敵の振る舞いを変える。
- `KING密着`、`前衛展開`、`対空優先`、`市街地防衛`のような一回の命令で数十秒の挙動を変えられるようにする。
- 機兵に損傷、修理、武勲を残し、生存者を観察対象にする。
- 道路閉鎖、煙幕、避難車両、建物倒壊を入れ、地図を戦闘の当事者にする。
- KINGに到達する敵数、最後に止めている機兵、残り防衛線を即読できるようにする。

### Network Defense Observer

人格、hotspot、イベント、介入はすでに良い基盤である。ネットワークを“生き物”として見せる方向が有効。

- 感染を系統化する。高速拡散型、潜伏型、重装型、偽装型など。
- Senior、Mid、Juniorに因縁と記憶を持たせる。前回失敗した経路、守り続けるノードなど。
- 安全圏、係争地、感染圏を面として見せ、前線を読むゲームにする。
- Signal Stormなどのイベント終了後にも不安定化や通信遅延を残す。
- 安定時は、次の侵入方向、防衛の過剰投資、孤立ノードといった“静かな緊張”を見せる。
- Breach Spikeを難易度上昇ではなく、どの区域を犠牲に全体を鍛えるかという選択にする。
- 勝利時に波数だけでなく、中央集権的な安全網、回復力の高い分散網、周辺を切り捨てた防衛など、完成したネットワークの性格を報告する。

### AI Colony Sandbox

勝敗より社会の変化を見せられるため、長時間放置の主力候補になり得る。

- 派閥に安定、名誉、知識、聖地、環境保全などの価値観を与える。
- 世界の記憶を持たせる。嵐で北部を見捨てた、難民を救った、交易を破ったなど。
- 中立勢力を空白地帯にせず、難民、交易商、宗教集団、海賊、技術者にする。
- 領土拡大に統治コスト、治安、補給、文化摩擦の副作用を付ける。
- 平和な回でも交易、移民、技術拡散、祭りが見どころになるようにする。
- 介入を神の手ではなく、地名、原因、後遺症を持つ世界イベントにする。
- リーダー交代、世代交代、思想変化を入れ、放置時間の長さに意味を出す。

### City Traffic

現状の交通可視化を、都市の意思決定を見るゲームに変える。

- 車種に配送、救急、通勤、工事、観光などの目的を持たせる。
- 渋滞を数値でなく「救急車が間に合うか」「物流契約が破綻するか」で意味付ける。
- 事故、工事、イベント、雨、通学時間で交通パターンを変える。
- 都市AIが信号優先、道路拡張、車線閉鎖を選び、その結果を評価する。
- 地域ごとに裕福、工業、住宅、観光などの事情を持たせる。

### MOSS / Network Small World

数理可視化から、変化する生態・社会の観察へ寄せる。

- MOSSのpacketを生物種として扱い、共生、捕食、寄生、突然変異、絶滅を入れる。
- Network Small Worldのノードを、情報ハブ、流行発生地、孤立した村、橋渡し役として意味付ける。
- リンク一本の追加・削除が、文化圏、情報伝播、隔離、流行を変えるようにする。
- どのノードが社会を救ったか、または壊したかを終了時に示す。

### Submarine Cables

現実データの地図表示を、依存関係の観察ゲームに変える。

- 障害、迂回、復旧船、国際的な帯域依存をシミュレーションとして載せる。
- 海底ケーブルの切断が、都市交通、金融、研究、通信などにどの順で影響するかを見せる。
- 復旧の優先順位が各国・企業の性格を表すようにする。

## 優先順位

### すぐ効く

1. 全ゲームへ「次の転換点」の一文を追加する
2. 重要イベントへ因果3段ログを追加する
3. 終了時に名場面・事件年表を残す
4. 介入後に短い余波を残す
5. 重要ユニット、船団、地点に限定して名前を付ける

### 中期で効く

1. Planet Strategyの補給線、占領後安定化、敗残勢力
2. Escort TDの敵作戦、部隊関係、道路の変化
3. Network Defenseの感染系統、前線、エージェントの記憶
4. Colonyの社会的記憶、中立勢力、世代交代
5. 中継・ドキュメンタリー型カメラ

### ゲームの芯を変える

1. 各ゲームに、観察者が予想できる局面を作る
2. 単発のランダムイベントを、原因が次の事件を生む連鎖へ変える
3. 勝敗だけでなく「この世界がどんな結末になったか」を持ち帰らせる
4. 介入を最適化操作ではなく、世界への問いかけにする

## 判断のためのチェックリスト

機能を追加する前に、以下の質問へ答える。

- この機能は30秒後の観察対象を作るか
- 観察者は起きる前に予兆を読めるか
- 結果が出た後、原因を追えるか
- AIの人格または世界の記憶を強めるか
- 介入後に新しい秩序か余波が残るか
- 数字を増やすだけでなく、話したくなる一場面を作るか

このうち複数に「はい」と答えられないなら、ゲーム性より実装量だけを増やす機能である可能性が高い。
