# GRAVITY GUNSHIP 実装フェーズ

設計書 `GAME_DESIGN_GUNSHIP.md` を、各フェーズ単体でも遊べて検証できる順序に分割する。
素材調達や DQN は、物理と観察性が確定してから進める。

| Phase | 範囲 | 完了条件 | 状態 |
|---|---|---|---|
| 1. Flight sandbox | 重力、機首一体型推力、海面、手動デバッグ、姿勢と推力炎の描画 | 上昇→降下射撃→復帰のリズムを手動で再現できる | 完了 |
| 2. Combat loop | 戦艦・空中機・敵弾、被弾、Wave、自動再出撃 | 戦艦を倒すために降下が必要で、落下／被弾でエピソードが終わる | 完了 |
| 3. Learning baseline | 構造化観測、Tabular Q、報酬、ローカル保存、学習HUD | 同じブラウザで学習状態が保持され、落下と撃破が方策に反映される | 完了 |
| 4. Run progression | XP、レベルアップ、推力・回頭・砲の実ラン効果 | 強化選択が**5秒間**表示され、未選択時はRLの強化選択方策が学習に基づき選ぶ | 完了 |
| 5. Watchability pass | 高度予測、危険ビネット、バースト周期・命中率の履歴 | 操縦の上達をHUDと機体の動きの両方で読める | 完了 |
| 6. Content & persistence | 敵種追加、ボス、機種システム、恒久研究、世代比較、セーブ設計 | 継続進行と異なる機体／世代の比較が成立する | 完了 |
| 7. Art polish | パララックス、専用スプライト、爆発・水柱・海面演出 | プロシージャル表現を専用アセットへ安全に差し替えられる | 進行中（プロシージャルFX） |

## Phase 6 で入った主要素

- **機種システム**（`gunship_airframes.ts`）：Interceptor / Hauler / Darter / Hoverer の4機種＝物理定数セット（TWR・旋回・推力ON時旋回低下k・drag・HP）。RANDOM/指定で選択、**入替でランをリセット**、学習モデルは**機種別にlocalStorage保持**（別々に育つ4パイロット）。
- **推力ON時の旋回低下**（LUFTRAUSERS要素）を物理に実装（`turnRate * thrustTurnK`）。
- **レベルアップのRL化**：強化選択を独立したTabular Q方策（3スロット選択）で学習。報酬は選択間に稼いだリターン。人間は5秒以内に上書き介入可。
- **敵弾の観測＋回避学習**：観測に「接近中の最寄り敵弾距離」を追加。
- **潜水艦（Submarine）**：潜行中は無敵、浮上した短時間だけ撃てる／撃たれる。
- **天井ソフト境界＋横トロイダルラップ**（画面外に消えない）、天井滞在への負報酬（籠りハック対策）。
- 命中率メーターの分母バグ修正（ミサイルを計上）。

## フェーズの運用

- 各 Phase の完了時に `npm run typecheck` を実行する。
- UI を伴う Phase は `npm run test:apps` も実行し、Electron で `npm run start:gunship` を手動確認する。
- Phase をまたぐ作業は、前の Phase の完了条件を壊さないことを優先する。
- Tabular Q は Phase 3 の基準線であり、DQN／階層方策への置換は Phase 6 以降に検討する。
