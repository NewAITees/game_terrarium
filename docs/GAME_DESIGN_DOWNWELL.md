# Downwell 調査 & 要件ドキュメント

> ステータス: **要件確定（未実装）／方向性①=AI箱庭観察の新作で確定**
> 目的: 名作 *Downwell*（もっぴん／Devolver, 2015）のコアメカニクスを分解し、
> 本箱庭シリーズ（[series-purpose-observation-sandbox] = 「AI箱庭観察」）への落とし込み要件を整理する。
> 出典は末尾の「参考リンク」を参照。

---

## 0. 本作の確定要件（Downwell からの改変点）

> ユーザー指定により、本作は Downwell を下敷きにしつつ以下を**確定仕様**とする。

- **AIが自動で潜る観戦もの**（操作でなく観察が主目的。シリーズ方針通り）。
- **ランダムダンジョン生成**：毎ステージ手続き生成（プラットフォーム／破壊可能ブロック／敵配置）。
- **1画面 = 1ステージ**：Downwell の WAVE の代わりに **1画面ぶんの縦穴**を1単位とし、
  **画面下端まで降り切ると次ステージ**へ遷移（＝ステージ = ミニ縦穴の連結）。
- **銃は全方位に向けられる**（Downwell との最大の差分）：
  真下固定ではなく**任意方向に発砲でき、反動で撃った方向の反対へ加速**する。
  → 「下に撃って上に浮く」だけでなく、**斜め・横に撃って軌道を作りながら潜る**立ち回りが成立。
- **敵が配置される**（撃破・回避の対象）。
- **リロード**あり（弾は有限。着地／踏み等でリロード＝下記 §2.1 準拠、詳細は実装で調整）。
- **銃の種類**あり（マシンガン／ショットガン／レーザー等、弾数・威力・反動が異なる）。

---

## 1. Downwell とは（一行）

**縦穴（井戸）をひたすら"落下"しながら、足に履いた銃「ガンブーツ」で敵を撃ち・踏み、
宝石を集めて底を目指す縦スクロール型ローグライク。**
色数は基本 **3色（赤・白・黒）**、1プレイ数分、`one more game` を誘発する高リプレイ性が特徴。

---

## 2. コアメカニクス分解

### 2.1 ガンブーツ（1ボタンが4役を兼ねる）

Downwell 設計の核心。**空中でジャンプ／射撃ボタンを押すと足元に発砲**し、これが同時に：

| 機能 | 内容 |
|------|------|
| ① 減速 | 発砲の反動で落下速度が落ち、**滞空時間が伸びる**（＝空中制御） |
| ② 攻撃 | 真下の敵にダメージ。地形（赤ブロック）も破壊して**通路を開く** |
| ③ 回避 | 滞空を伸ばして着地タイミング＝危険地帯を回避 |
| ④ 探索 | 下方向の地形破壊で宝石やアイテムを掘り出す |

- **弾数は有限**（初期マシンガンは8発）。**着地する / 敵を踏む** と弾がリロードされる。
- → 「撃って浮く」と「弾切れ」が相反し、**空中に居続けられない**緊張を生む（Ikaruga の弾幕 × Resident Evil の弾管理）。

### 2.2 踏みつけ（ストンプ）

- 一部の敵は**頭上から踏むと即撃破 + 弾リロード**。ただし赤い敵は踏めず接触ダメージ。
- 「撃つ or 踏む」の即断が常に走る。

### 2.3 コンボ

- **地面に着地せず**に敵を連続撃破するとコンボカウンタ +1。
- コンボは以下では**継続**する：置物（doodad）踏み、ステージ間移動、セーフゾーン着地、壁ジャンプ、**空中で被弾しても**。
- 純粋な地面着地でリセット。
- 節目でボーナス（宝石大量獲得など。目安 **8 / 15 / 25**、25 以降は追加報酬が頭打ちのため、あえて切って稼ぐ立ち回りも）。
- → コンボは**実質的な難易度スライダー**。安全に落ちるだけなら無視でき、稼ぎたいほどリスクを取る自己申告制の挑戦。

### 2.4 宝石（ジェム）と「ジェム・ハイ」

- 敵撃破や地形破壊で宝石がドロップ。ショップ通貨兼スコア。
- **一定数（例: 100）集めると「ジェム・ハイ」**状態に入り、以降の宝石獲得が倍化。ただし宝石を取り逃がすと解除。
- → **速く落ち続ける**ほど得をする、テンポへの正のフィードバック。
- 宝石総量はゲームオーバーをまたいで**累積**し、しきい値で「スタイル」等をアンロック（メタ進行）。

### 2.5 ショップ & パーク & スタイル

- フロアの合間に**ショップ**：HP+1 / 弾数+2 / モジュール等を宝石で購入。
- フロア突破ごとに**パーク（3択の恒常ボーナス）**を選択 → ビルドが分岐。
- **武器の強制交換**（Super Crate Box 型）：新武器を拾うと現武器と交換。交換時に HP+1 か 弾数+2 の報酬。
  - 武器例: マシンガン（8発, 汎用）/ ショットガン・レーザー（高威力・多弾消費）等 → 弾管理の駆け引きが武器ごとに変わる。
- **スタイル（キャラ）**：初期ステータス・所持モジュールが異なる複数キャラをアンロックで解放。

### 2.6 難易度カーブ（プレイヤー成長の3段階）

出典の分析いわく、上達は自然に3段階を辿る：

1. **生存フェーズ** — まず底まで落ちて死なない
2. **速度フェーズ** — ジェム・ハイを維持してテンポよく落ちる
3. **コンボフェーズ** — 着地せず連続撃破で稼ぐ、最高難度の自己表現

## 3. ビジュアル / フィール要件

- **3色パレット**（既定は赤・白・黒）。**色に意味を持たせる**：赤 = 危険（踏めない敵・破壊可能地形）。
  情報を色数ではなく「役割」で伝えるミニマル設計。
- アンロックでパレット変更・**1bit グラフィック**切り替え。
- 画面は**縦長**（井戸）。カメラは落下に追従、上方向へは戻れない（後戻り不能の緊張）。
- 短いフィードバックループ：発砲反動・踏み・撃破の手応えを**過剰なほど即時**に返す（画面揺れ・音・粒子）。

## 4. 本シリーズ（AI箱庭観察）への要件落とし込み

> シリーズ方針 [series-purpose-observation-sandbox]：**操作でなく観察が主目的**。
> Downwell はアクションの塊なので、そのまま移植ではなく「**AIが落下を攻略していく様を眺める**」に変換する。

### 4.1 観戦フレームへの読み替え

| Downwell の原理 | 箱庭観察での見せ方 |
|------|------|
| 撃つ/浮く/踏むの一手選択 | エージェントが毎フレーム選ぶ**行動の可視化**（なぜ今撃った/浮いた） |
| 弾数×滞空のトレードオフ | 「弾を使い切って落ちるか、踏んで粘るか」の**方針が観測に出る** |
| コンボ = 自己申告の難度 | 学習が進むほど**コンボ長が伸びる**＝上達が数字で見える観戦価値 |
| ジェム・ハイ | 速く落ち続ける安定飛行に入れているか＝**習熟のバロメータ** |
| 3段階成長（生存→速度→コンボ） | まさに**RLエージェントの学習曲線**として観察対象になる |

### 4.2 最小実装要件（MVP）

- [ ] **ランダムダンジョン生成**：1画面ぶんの縦穴を手続き生成（プラットフォーム＋破壊可能ブロック＋敵配置、シード管理）
- [ ] **1画面=1ステージ遷移**：画面下端を通過したら次ステージを生成して継続（深度カウント）
- [ ] **全方位射撃の物理**：任意方向に発砲 → 反動で反対方向へ加速。有限弾、着地・踏みでリロード
- [ ] 銃の種類（最低2〜3種：マシンガン/ショットガン/レーザー。弾数・威力・反動が異なる）
- [ ] 踏み判定（頭上ヒット）と接触ダメージ（赤敵）
- [ ] コンボカウンタ（着地でリセット、継続条件を実装）と節目ボーナス（8/15/25）
- [ ] 宝石ドロップ＋ジェム・ハイ（しきい値で倍化）
- [ ] 3色レンダリング（Canvas 2D で十分）、縦長カメラ追従
- [ ] **RLエージェント接続**（`shared/rl/tabular_q_agent.ts` 流用）—
      観測: 直下＆周囲の危険/最寄り敵の相対方位/弾数/落下速度/コンボ帯、
      行動: **8方位いずれかに撃つ / 撃たず落下 / （必要なら）待つ**（＝射撃方向が行動空間に入る）
- [ ] 学習HUD：現在のQ値/選択理由・エピソードごとの**到達深度**・最大コンボのトレンド

### 4.3 観察価値を担保する4点（シリーズ共通評価軸）

1. 🎯 **"なんとなく"では底まで行けないか** — 弾管理と着地回避が要る骨格
2. 👁 **一手の意味が目で読めるか** — 弾数・落下速度・直下の脅威を明示
3. 🧠 **AIの上達が可視化されるか** — 到達深度・コンボ長の学習曲線
4. ♾ **放置で変化が続くか** — シード変化 & 学習の積み上げ

## 5. 実装スケッチ（提案）

- 配置: `apps/downwell/`（`downwell.ts` / `downwell.html` / `downwell_physics.ts` / `downwell_render.ts` / `downwell_rl.ts`）
- 描画: Canvas 2D、縦長、3色。Three.js は不要。
- RL基盤: `shared/rl/tabular_q_agent.ts` を流用（[one-line-rpg-direction] と同構成）。
- CLAUDE.md ルール順守: 全 `.ts`、`vite.config.ts` と `tsconfig.json` にエントリ追加。
- ページ登録: `main.js` の named page に `downwell` を追加（Ctrl ショートカット）。
