# Zombie Survivor — WAVE制サバイバルゲーム企画書

> ステータス: 初期設計
> 仮題: **ZOMBIE SURVIVOR: LAST OUTPOST**
> 更新日: 2026-07-27
> 関連資料: `docs/GAME_DESIGN_RL_ARENA.md`

## コンセプト一行

**大量のゾンビを自動攻撃で殲滅し、限られた食料と燃料を確保しながらWaveを生き残り、
戦闘の合間の作業タイムで拠点と装備を成長させる観察型サバイバルゲーム。**

## ゲームの柱

1. **Waveを生き残る** — 敵の種類と出現方向を読み、武器ビルドで大群を処理する。
2. **倒した敵を報酬へ変える** — 撃破数と敵の種類に応じて経験値、資材、食料、燃料を得る。
3. **作業タイムで次の戦闘を準備する** — レベルアップ、武器強化、探索、修理、資源配分を行う。
4. **資源が尽きる前に前進する** — 戦闘能力だけでなく、食料と燃料の収支を維持する。

## 目標としないもの

- プレイヤーの反射神経だけを試す手動ツインスティックシューター
- 敵HPだけを増やし続ける単純な数値インフレ
- 作業メニューを何度も開かないと進行できない複雑な管理ゲーム
- 資源不足で長時間何もできなくなる詰み状態

## コアループ

```text
出撃準備
  ↓
戦闘Wave（自動攻撃 / 移動 / 撃破 / 資源回収）
  ↓ Wave突破
報酬確定（経験値・弾薬素材・食料・燃料）
  ↓
作業タイム（レベルアップ・武器強化・拠点作業・探索）
  ↓
次Waveへ出撃
  ↓
敗北 → 最終報酬と恒久成長 → 再出撃
```

### 1回のWave

1Waveは30〜90秒を基本とする。開始時に敵編成と危険要素を短く予告し、通常群、混成群、
Eliteまたはボスの順に圧力を上げる。Wave突破時には画面上で報酬を明示し、次の作業タイムへ遷移する。

5Waveを1サイクルとし、1、2、3、4Waveで敵の量・速度・種類を上げ、5Waveを試験Waveとする。
25Waveごとにエリア、敵Modifier、資源効率を更新する。最終Waveは置かず、最高到達Waveを長期目標にする。

## プレイヤーと強化学習エージェントの役割

通常の戦闘は強化学習エージェントが担当する。エージェントは移動、回避、標的選択、攻撃、
危険な敵への対応を学習する。プレイヤーは画面を観察しながら、作業タイムの方針、恒久研究、
報酬設計へ介入する。手動操作はデバッグと教師データ収集用に用意する。

エージェントは戦闘だけでなく、Wave間の作業方針も選択する。休憩時の育成選択は、プレイヤーと
エージェントが半分ずつ担当する。具体的には、4つの育成候補のうち2枠をエージェントが自動選択し、
残り2枠はプレイヤーが選ぶか、未操作時はエージェントが選ぶ。「食料優先」「燃料優先」「火力優先」
「修理優先」の判断が、次Waveの生存率と資源収支に影響するようにする。

作業タイムでは次を選択する。

- 経験値による3択レベルアップ
- 所持武器の強化、武器の解放、武器進化
- 拠点の修理、バリケードや保管庫の整備
- 周辺探索による食料・燃料・素材の回収
- 次Waveへ持ち込む物資とリスクの決定

作業タイムは原則20〜45秒とし、未操作でも推奨行動を自動実行して再出撃する。

## 戦闘と成長

### ラン内成長

敵を倒すと経験値がその場に落ち、一定量を集めるとレベルアップする。レベルアップは戦闘を一時停止し、
3つの候補から1つを選ぶ。候補は以下のカテゴリを混ぜる。

| カテゴリ | 例 | 役割 |
|---|---|---|
| 武器 | ピストル、ショットガン、火炎瓶、電撃、地雷 | 攻撃手段を増やす |
| 武器強化 | 威力、連射、範囲、貫通、弾数 | ビルドの軸を伸ばす |
| 生存 | 最大HP、回復、移動速度、拾得範囲 | 大群から生き残る |
| 資源 | 収集効率、燃費、食料保存、追加ドロップ | 長期走行を支える |

同じ武器を一定レベルまで上げ、対応するパッシブを取得すると武器進化を解放する。
進化は数値上昇だけでなく、発射パターン、範囲、効果音、撃破時の見た目で強化を認識できるようにする。

### 敵の報酬

敵種ごとに「戦闘価値」と「物資価値」を分ける。強敵を倒すほど多くの報酬を得られるが、
接近や弾薬消費のリスクも高くする。

| 敵 | 戦闘上の役割 | 主な報酬 |
|---|---|---|
| Walker | 数で圧迫する基本敵 | 経験値、少量の食料 |
| Runner | 高速接近 | 経験値、燃料の小箱 |
| Spitter | 遠距離攻撃 | 素材、弾薬部品 |
| Brute | 高耐久の壁 | 大量経験値、食料、素材 |
| Carrier | 倒すと物資を落とす | 食料または燃料 |
| Boss | Waveの試験 | 大型報酬、恒久通貨、武器素材 |

## 資源システム

最低限の必須資源は食料と燃料とする。資源はラン中の行動を制限するが、尽きた瞬間に即ゲームオーバーにはしない。

| 資源 | 消費 | 獲得 | 不足時 |
|---|---|---|---|
| 食料 | Waveごとの生存、作業人数、回復 | Walker、Carrier、探索、拠点生産 | 最大HPと回復効率が低下 |
| 燃料 | 移動、発電、探索、拠点設備 | Runner、Carrier、車両探索 | 探索不可、設備効率低下 |
| スクラップ | 武器強化、バリケード修理、弾薬工作 | 敵、解体、探索 | 装備強化・修理・弾薬工作が止まる |
| 物資クレジット | 作業タイムの特殊行動 | Wave突破、Boss、実績 | 一部の高度な作業を選べない |

### 収支ルール

各Wave開始時に予測収支を表示する。

```text
次Wave予測食料 = 現在食料 - 生存消費 + 前Wave報酬 + 探索見込み
次Wave予測燃料 = 現在燃料 - 移動/発電消費 + 前Wave報酬 + 探索見込み
```

食料と燃料が赤字の場合、作業タイムに「補給を優先」「武器強化を優先」「危険な探索」の判断を提示する。
資源は一定量を超えて貯められ、保存容量の拡張も恒久成長に含める。

## 作業タイム

作業タイムは戦闘の合間に必ず発生する短い準備フェーズである。画面左に現在資源、中央に作業候補、
右に次Waveの予告を表示する。

## 武器種と弾薬

武器は近接武器と遠距離武器に分ける。近接武器は弾薬を消費しない代わりに、接近時の被弾リスクと
攻撃範囲の狭さを持つ。遠距離武器は安全な距離から攻撃できるが、弾薬を消費する。

出撃時は近接メイン、遠距離メイン、予備武器を選択する。ラン中は作業タイムでスクラップを使って
武器を強化し、状況に応じて装備を切り替える。

| 種別 | 例 | 弾薬 | RLが学ぶこと |
|---|---|---:|---|
| 近接 | バット、ナイフ、チェーンソー | 0 | 接近距離、退避、攻撃タイミング |
| 遠距離 | ピストル、ショットガン、ライフル | 1〜5 | 標的優先度、弾薬温存、射程管理 |

### 武器候補

| 武器 | 種別 | 特徴 |
|---|---|---|
| ハンマー | 近接 | 高威力、ノックバック、単体向き |
| ナイフ | 近接 | 高速、連続攻撃、低威力 |
| ハンドガン | 遠距離 | 扱いやすい標準武器 |
| ショットガン | 遠距離 | 扇状攻撃で大群に強いが弾薬消費が大きい |
| ライフル | 遠距離 | 安定した連射と射程 |
| スナイパー | 遠距離 | EliteやBossへ大ダメージ、発射間隔が長い |
| 火炎瓶 | 予備 | 地面に継続ダメージの炎を残す |
| 手榴弾 | 予備 | 一時的な広範囲爆発 |
| クロスボウ | 予備 | 静かで貫通する単発攻撃 |

弾切れ時は近接武器へ自動切り替えし、操作不能や即時敗北にはしない。予備武器は作業タイムに
指定でき、エージェントは敵密度、残弾、クールダウンを見て使用する。

弾薬は敵撃破、探索、工作で補給できる。弾切れでも近接武器へ自動切り替えし、操作不能や即時敗北にはしない。
エージェントの報酬には、遠距離武器の有効な使用、弾薬の無駄撃ち抑制、弾切れ後の近接切り替えを含める。

## 破壊可能コンテナ

戦闘フィールドには木箱、ロッカー、車のトランク、補給コンテナを配置する。破壊すると通常の敵ドロップとは
別に弾薬とスクラップを追加で落とす。コンテナを狙う間はゾンビへの攻撃が減るため、壊すタイミング自体が
RLエージェントの標的選択課題になる。

| コンテナ | 耐久 | 主なドロップ |
|---|---:|---|
| 木箱 | 低 | 弾薬、少量スクラップ |
| ロッカー | 中 | 弾薬、回復アイテム |
| 車のトランク | 中 | 燃料、弾薬 |
| 補給コンテナ | 高 | 大量スクラップ、予備武器、弾薬箱 |

### 作業コマンド

| コマンド | 効果 | コスト／リスク |
|---|---|---|
| 休息 | HPを回復 | 食料を消費 |
| 修理 | バリケードと装備を回復 | スクラップを消費 |
| 探索 | 食料・燃料・素材を取得 | 燃料を消費、低確率で襲撃 |
| 発電 | 次Waveの設備と照明を強化 | 燃料を消費 |
| 工作 | 回復薬、弾薬、罠を作成 | 素材を消費 |
| 強化 | 武器または拠点設備を強化 | 物資クレジット／素材を消費 |

### スクラップの使い道

スクラップは武器強化に必須とし、修理や弾薬工作と共通の有限資源にする。
エージェントは「次Waveを越えるための火力」と「将来の弾薬・修理余力」を比較して使い道を選ぶ。

| 行動 | 初期コスト | 効果 |
|---|---:|---|
| 近接武器強化 | 8 | 威力、範囲、攻撃速度のいずれかを上昇 |
| 遠距離武器強化 | 10 | 威力、射程、装弾数のいずれかを上昇 |
| 弾薬工作 | 4 | 遠距離弾薬を5発補充 |
| バリケード修理 | 6 | 拠点耐久を回復 |

同じ武器を強化するたびにコストを1.35倍へ増加させる。Wave突破報酬、Brute、Boss、探索から
まとまったスクラップを得られるため、強化を我慢して貯める選択にも意味を持たせる。

「次Waveへ進む」は常に利用可能にし、資源不足で進行不能にはしない。ただし不足した状態で進むと、
戦闘開始時の不利なModifierや選択肢の減少が発生する。

## 敗北と恒久成長

プレイヤーまたは拠点が倒れた時点でWave、撃破数、獲得資源、武器ビルドを確定する。
ラン中の武器レベルは失うが、Boss報酬や研究ポイントは恒久的に残る。

恒久成長の例:

- 初期食料・燃料の増加
- 探索で見つかる資源量の増加
- 初期武器と解放済み武器の追加
- 最大HP、拾得範囲、作業時間の延長
- 新しい敵エリアと武器進化の解放

強化後はWave 1から再開するが、初期状態が強くなり、以前の到達点をより速く越えられる。

## 最低限の実装範囲（MVP）

### Phase 1: 戦闘の成立

- 1画面の2Dフィールド
- プレイヤー移動と自動射撃
- Walker、Runner、Bruteの3種類
- 5Wave構成とWave突破判定
- 敵撃破時の経験値、スクラップ、食料、燃料ドロップ
- HP、Wave、撃破数、資源のHUD

### Phase 2: 成長と作業タイム

- XPによる3択レベルアップ
- 武器3種と武器レベル
- Wave間の作業タイム
- 休息、探索、修理、武器強化
- 資源不足による軽い不利
- 敗北後の報酬確定と再出撃

### Phase 3: 長期構造

- BossとCarrier
- 武器進化
- 恒久研究とセーブ
- 25Waveごとのエリア更新
- 自動作業方針（食料優先／燃料優先／火力優先）

## 強化学習設計

戦闘中は敵の方向・距離・密度、敵弾、HP、武器状態、食料、燃料、Wave進行、次Waveの危険度を観測し、
移動・回避・ブーストダッシュ・標的・攻撃を選択する。作業タイムでは探索、修理、強化、休息などの高レベル行動を選択する。

```text
観測 → 戦闘方策 → 移動 / 回避 / ブーストダッシュ / 標的 / 攻撃
  ↓ Wave突破
資源・HP・次Wave予告 → 作業方策 → 探索 / 修理 / 強化 / 休息
```

報酬は撃破数だけに偏らせず、生存、Wave突破、資源確保、被弾回避、不要な資源消費の抑制を組み合わせる。
敗北はエピソード終了として学習データと恒久報酬を確定し、自動的に次の出撃へ進む。

### ブーストダッシュ

ブーストダッシュは通常移動とは別の緊急回避アクションとする。入力方向へ短時間高速移動し、開始直後は
無敵になる。使用には燃料を1消費し、8秒のクールダウンを置く。エージェントは敵弾の接近、包囲、Bruteの
接触予兆を観測して使用する。無敵中に敵弾を回避できた場合は正の報酬、危険でない場面での浪費には小さな
ペナルティを与える。

プレイヤーはレベルアップの3択や作業タイムの候補を短時間だけ上書きできる。未操作の場合はエージェントが
選択する。人間の選択はエージェントの行動と混同せず、教師介入として別ログに記録する。

## 実装方針

既存の`apps/arena-shooter/`にある自動射撃、Wave、XP、3択強化、撃破報酬、恒久研究の設計を再利用できる。
本作ではAI学習を必須要件とし、通常プレイそのものを強化学習エージェントが担当する。
ラン状態、作業状態、恒久状態、学習状態を分離し、同じWaveと報酬計算でプレイヤー介入時と自律時を比較できるようにする。

```ts
type ZombieRunState = {
  wave: number;
  level: number;
  xp: number;
  hp: number;
  weapons: Record<string, number>;
  food: number;
  fuel: number;
  scrap: number;
  pendingWork: boolean;
};

type ZombieMetaProgress = {
  highestWave: number;
  totalKills: number;
  researchPoints: number;
  startingFoodLevel: number;
  startingFuelLevel: number;
  unlockedWeapons: string[];
};

type ZombieLearningState = {
  policyVersion: number;
  epsilon: number;
  steps: number;
  episodes: number;
  states: number;
  lastAction: string;
  interventionCount: number;
};
```

## 成功条件

- 5分間、戦闘・報酬・作業タイムの流れが止まらない
- 1Waveごとに「何を倒し、何を得て、何に使ったか」がHUDで分かる
- 10分以内に武器または拠点の目に見える変化が起きる
- 食料と燃料を確保する判断が、単なる火力強化と異なる意味を持つ
- 敗北後も恒久成長によって再挑戦の改善が実感できる
- 資源不足でも詰みにならず、危険を受け入れて再起できる

## 次の検証項目

1. エージェントが1Waveの戦闘と作業タイムの両方を継続して選択できるか。
2. 1Waveの長さと作業タイムの長さが、観察しやすさとテンポを両立しているか。
2. 食料・燃料の消費量が、毎回探索を選ぶ固定解になっていないか。
3. 敵撃破報酬が、敵を避けるより倒す方が魅力的になる量か。
4. 武器強化と資源強化のどちらを選ぶかに、Wave編成による差が出るか。
5. 画面上の敵数とドロップ数が増えても、戦況を認識できるか。
